Release Notes

0.3.0

    * reset process is much less invasive, it just resets components rather than shutting down and rebooting the emulator

0.2.0 (September 1, 2026)
** Motion can now boot GL2 Unix in serial mode only. A disk image is provided at: xxxxx**

    * Video scaling (thanks to flexion)
    * Added --help command-line option (also --h and -?) for common convars (thanks to flexion)
    * a launcher that lets you configure the most common settings
    * lisburn: hardcode DASM and register info to ON since we really don't need them to be an option
    * lisburn: fix 68020 format B stack frames
    * Fix emulator input being sent to main emulator as well as IMGUI
    * Fix shift and ctrl keys 
    * Fix Filesystem::Seek being broken
    * Fix busted back switches impl (was using pm2's???)
    * Fix issue involving init order causing first instruction to be corrupted, this was harmless until bus errors were a thing
    * Fix unaligned memory access (initial version by danifunker, rewritten by me)
    * Multibus: megabyte multibus memory is now emulated
    * Multibus: multibus paging is now emulated
    * Multibus: multibus slave behaviour is now emulated (thanks danifunker)
    * Multibus devices now use the SlotMapping class instead of the SLot class, they can map any number of regions now instead of being limited to 20 Multibus slots with one mapping each.
    * Memory / VRAM editors (CoherentEditor) now have an ASCII view.
    * change description of bp3 from "BP3 Bitplaned VRAM" to "Video RAM (BP3 bitplane board)" to make it easier to understand 
    * Added an SRAM viewer
    * Memory editors can now dump memory
    * added a cool logo
    * Assets are now in the assets folder
    * The last mapping read or written is now cached so we odn't have to linearly iterate through all mappings each time
    * Added ability to edit register values, click on them to edit them
    * DSD 5217 emulation (first version sucked, thanks danifunker)
    * IP2 interrupt emulation (thanks danifunker)
    * proper RTC emulation (thanks danifunker)
